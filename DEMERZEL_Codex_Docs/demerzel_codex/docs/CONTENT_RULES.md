# DEMERZEL Content Rules

## Source-grounded content

All catalogue-derived content must be traceable to the supplied
catalogues.

For each specification, retain an internal source reference: - source
document - page - extracted field - verification status

## Safe wording

Prefer: - "Designed for wildlife observation" - "The catalogue positions
this model for..." - "Waterproof" when explicitly stated - "Nitrogen
filled" when explicitly stated - exact technical specifications from the
catalogue

Avoid unless independently verified: - "military certified" - "combat
proven" - "government approved" - "NATO approved" - "official
distributor" - "exclusive distributor" - "best in class" - "number
one" - "field tested" - "used by \[organization\]" - performance claims
such as "guaranteed detection at X km"

## Product descriptions

A product description should contain: 1. what the product is 2.
source-supported intended use 3. important technical characteristics 4.
environmental/field characteristics if stated

Do not add technical explanations that imply a performance guarantee.

## Comparison copy

Comparison must use actual stored specifications.

Good: "10X provides higher magnification than 8X."

Avoid: "10X is always better."

Use neutral "best suited for" language only where the source specs and
use cases support it.

## Missing data

Display: "Contact DEMERZEL for availability and commercial details."

or:

"Specification not provided in current catalogue."

Do not fabricate.

## Reviews

Do not create reviews until real review data exists.

## Prices

Do not create prices from catalogue context. Price is a separate
commercial data field.

## Images

Do not present generic stock images as the actual product.

Use clear labels where an image is illustrative.

## Projects

Never invent: - project location - customer name - outcome - deployment
scale - performance results

## Third-party brands

Catalogue presence does not equal authorization.

Use: "Featured in the DEMERZEL catalogue"

until commercial status is verified.
