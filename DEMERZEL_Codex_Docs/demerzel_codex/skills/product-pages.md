# Skill: Product Pages

## Goal

Build premium, technical product pages that allow customers to
understand and compare equipment.

## Required order

1.  Breadcrumbs
2.  Product gallery
3.  Product name
4.  short description
5.  applications
6.  key features
7.  CTA
8.  technical specifications
9.  model comparison
10. documents
11. related products
12. support
13. enquiry

## UX

-   Sticky purchase/enquiry panel on desktop
-   clear CTA
-   mobile sticky CTA
-   specification groups
-   copyable SKU
-   accessible image gallery
-   responsive comparison

## Rules

Never display: - fake ratings - fake reviews - fake stock - fake price -
fake certifications

When commercial data is unavailable: - show enquiry CTA - say "Contact
DEMERZEL for commercial details"

## Technical table

Use semantic table markup on desktop and an accessible stacked
representation on narrow screens.

Example groups: - Optical - Field of View - Physical - Environmental
