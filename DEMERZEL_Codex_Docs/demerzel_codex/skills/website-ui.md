# Skill: DEMERZEL Website UI

## Visual direction

The site should feel: - field-oriented - technical - premium -
restrained - professional

Use strong product photography and real catalogue imagery where
available.

## Avoid

-   generic marketplace layouts
-   excessive visual effects
-   noisy gradients
-   fake metrics
-   fake trust badges
-   fake testimonials

## Components

Build reusable: - Header - MegaMenu - Footer - Hero - MissionCard -
ProductCard - ProductGrid - ProductFilters - ProductSpecTable -
CompareDrawer - QuoteCTA - SolutionCard - BrandCard - ResourceCard -
AccountSidebar - DashboardCard - StatusBadge - EmptyState - ErrorState -
LoadingSkeleton

## Responsive behavior

Desktop: - full mega menu - multi-column product grids - comparison
table

Mobile: - drawer navigation - horizontally scrollable product cards
where useful - stacked specs - sticky CTA - filters in a modal/drawer
